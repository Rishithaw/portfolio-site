## Overview

This project is a **React + TypeScript portfolio website**, built using the UI Component Library from previous assignments.
The site showcases:

- Basic student information
- Work and projects
- Skills, tools, and technologies
- Course resources
- Developer setup

The final deliverable is a **Dockerized production build** hosted with **Nginx** and accessible at:

**http://127.0.0.1:5575**
**http://localhost:5575**

---

## Project Structure

### Basic Information

- Name
- Program
- Email
- Summary

### Work / Projects

Each work entry includes:

- Title
- Description
- Image
- Link
- Tech list

### Skills

- Description
- Languages / Frameworks
- Tools

### Resources

Each resource entry includes:

- Title
- Image / Icon
- Summary
- Link

### Developer Setup

- VSCode setup
- Terminal setup
- Preferred editor font

```bash
# Clone the repository
git clone https://github.com/Rishithaw/portfolio-site.git
cd portfolio-site

# Install dependencies
npm ci

# Start the development server
npm start

# Site runs at:
http://127.0.0.1:5575
```
